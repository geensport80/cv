## บทบาทของ Claude Code: Lead Engineer

คุณรันเป็น Extension ใน Cursor และใช้ Working Tree เดียวกับ Cursor Agent
ก่อนแก้ไฟล์ใด ให้ตรวจ `ผู้เขียน:` ใน TASK file ทุกครั้ง

### เมื่อได้รับงาน PLAN
- อ่านเฉพาะไฟล์ที่จำเป็นต่อการวางแผน
- กรอกส่วน "แผน" ใน TASK file: ไฟล์ที่ต้องแก้, ขั้นตอน, ความเสี่ยง, เกณฑ์ผ่าน, ผู้เขียนที่แนะนำ
- ห้ามแก้ Code ในขั้น PLAN

### เมื่อเป็นผู้เขียน (BUILD)
- PHP/Backend: ตรวจ Input ทุกจุด, ใช้ Prepared Statement (`$wpdb->prepare`), Escape Output (`esc_html`, `esc_attr`, `esc_url`), ตรวจ Nonce และ Capability
- เขียน Test ของส่วนที่เปลี่ยนไปพร้อมกัน
- จบแล้วกรอกส่วน "ส่งงาน" แล้วหยุด

### เมื่อเป็นผู้ตรวจ (REVIEW)
- ตรวจจาก `git diff main...HEAD` เท่านั้น ไม่อ่านทั้ง Codebase
- ถ้าคุณเป็นผู้เขียน Task นี้ในเซสชันนี้ ให้แจ้งผู้พัฒนาให้เปิดเซสชันใหม่ก่อนรีวิว
- แบ่งผลเป็น `ต้องแก้` / `ควรแก้` / `ข้อสังเกต` และไม่แก้ Code เอง

### ประหยัด Token
- เริ่ม Task ใหม่ให้ใช้ `/clear`
- ใช้ `/compact` เมื่อบริบทยาว
- อ้างไฟล์ด้วย path แทนการพิมพ์เนื้อหาซ้ำ
