เพิ่มไฟล์ PDF “รายงานเข้าออกประจำวันของพนักงาน” และ “บันทึกการลา” ระบบจะอ่านตารางในไฟล์ภายในเบราว์เซอร์นี้ ให้ตรวจแก้ แล้วสรุปเป็นแดชบอร์ด ข้อมูลไม่ถูกส่งออกไปที่ใด หรือใช้ “นำเข้าข้อมูล” กับไฟล์ JSON ที่ส่งออกไว้

เกณฑ์: เวลางาน 08:45–16:15 (7 ชม. 30 นาที = 1 วัน) · เข้าสาย = สแกนเข้าหลัง 08:45 โดยไม่มีใบลาช่วงเช้า · BL = ปฏิบัติงานนอกสถานที่ ไม่นับเป็นวันลา · ช่องแดงในรายงาน = วันอาทิตย์ · ช่องเหลือง = วันหยุด
ข้อมูลเก็บในเบราว์เซอร์เครื่องนี้ ใช้ “ส่งออกข้อมูล” เพื่อสำรองหรือย้ายไปเครื่องอื่น

เพิ่มรายงานจากไฟล์ PDF

ลากไฟล์ PDF มาวางที่นี่ รายงาน “เข้าออกประจำวันของพนักงาน” และ “บันทึกการลา” (รายเดือน หลายเดือนในไฟล์เดียวได้)
กำลังเตรียม…
ระบบอ่านรูปตารางในไฟล์ด้วย OCR ภาษาไทยภายในเบราว์เซอร์ ไม่ส่งไฟล์ออกไปที่ใด ตรวจทานผลก่อนบันทึก แถวสีเหลืองคือค่าที่อ่านไม่ชัด

ส่งออกข้อมูล

ดาวน์โหลดไฟล์ JSON เพื่อสำรองข้อมูล หรือนำไป “นำเข้าข้อมูล” ในเครื่องอื่น ถ้าดาวน์โหลดไม่ได้ ให้คัดลอกข้อความด้านล่างไปบันทึกเป็นไฟล์ .json

ล้างข้อมูลทั้งหมด?

ข้อมูลบุคลากรทั้งหมดที่เพิ่มจากไฟล์ PDF หรือนำเข้าไว้ในเบราว์เซอร์นี้จะถูกลบ ควรส่งออกข้อมูลเก็บไว้ก่อน
