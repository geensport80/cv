# APDI สรุปการปฏิบัติงานบุคลากร

แดชบอร์ดแบบโต้ตอบ สรุปเวลาเข้า–ออกงานและการลาของบุคลากร APDI จากไฟล์ PDF
“รายงานเข้าออกประจำวันของพนักงาน” และ “รายงานบันทึกการลา”

## ใช้งาน
เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ (เช่น GitHub Pages หรือ `npx http-server apdi-dashboard`)
ไม่ควรเปิดแบบ `file://` เพราะเบราว์เซอร์จะไม่ยอมโหลดตัวอ่าน OCR

- **เพิ่มไฟล์ PDF** — ลากไฟล์มาวางหรือเลือกไฟล์ ระบบเรนเดอร์หน้า PDF หาเส้นตาราง แล้วอ่านทีละช่องด้วย OCR ภาษาไทย/อังกฤษ (Tesseract) ภายในเบราว์เซอร์ ไม่ส่งไฟล์ออกไปไหน จากนั้นแสดงตารางให้ตรวจแก้ก่อนบันทึก
- ข้อมูลเดือนเดียวกันของคนเดิมจะถูกแทนที่ด้วยไฟล์ใหม่ (ประมวลผลใหม่ได้ทุกครั้ง) คนใหม่จะถูกเพิ่มเป็นบุคลากรอีกคน
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ใช้ **ส่งออกข้อมูล** (JSON/CSV) และ **นำเข้าข้อมูล** เพื่อสำรองหรือรวมข้อมูลหลายเครื่อง

## ไฟล์
- `index.html` — หน้าแดชบอร์ด (กราฟ ปฏิทิน ตาราง ตัวกรอง)
- `ocr.js` — ตัวอ่าน PDF → ข้อมูล (หาเส้นตาราง, สีช่องแดง = อาทิตย์ / เหลือง = วันหยุด, OCR รายช่อง)
- `seed.js` — ข้อมูลตั้งต้น (ว่างไว้ ไม่เก็บข้อมูลบุคลากรในโปรเจกต์ — เพิ่มจาก PDF ในหน้าแดชบอร์ดแทน)
- `vendor/` — pdf.js 3.11.174, tesseract.js 5.1.1 และไฟล์ภาษา tha/eng (tessdata_fast) ฝังไว้ในโปรเจกต์ ใช้งานได้โดยไม่ต้องพึ่ง CDN

## เกณฑ์ที่ใช้คำนวณ
- เวลางาน 08:45–16:15 (7 ชม. 30 นาที = 1 วันลา)
- เข้าสาย = สแกนเข้าหลัง 08:45 โดยไม่มีใบลาช่วงเช้าครอบคลุม
- สแกนไม่ครบ = มีเวลาเข้าหรือออกอย่างเดียวในวันทำการ และไม่มีใบลาในวันนั้น
- BL (ปฏิบัติงานนอกสถานที่) และสลับวันหยุด ไม่นับรวมใน “วันลารวม”
